# AI Accounting Assistant

A full-stack accounting application for managing personal expenses, tracking spending, and viewing financial summaries through a dashboard.

## Features

- User registration and login
- JWT-based authentication
- Secure authenticated expense management
- Add new expenses
- Edit existing expenses
- Delete expenses
- View expense history
- Expense categories
- Total spending summary
- Total number of expenses
- Spending breakdown by category
- Recent expenses dashboard
- Responsive web interface

## Tech Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- JWT authentication

### Database

- PostgreSQL

### Development

- Git
- GitHub
- Python virtual environment
